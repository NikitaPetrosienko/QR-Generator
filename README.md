# QR vCard Microservice

**QR vCard MicroService** — микросервис для генерации **QR-кодов визиток (vCard 3.0)** сотрудников компании.  
Он формирует QR-код, содержащий ФИО, должность, подразделение, контакты и корпоративные данные,  
и возвращает готовое изображение **PNG** с логотипом компании и фирменными цветами.  
Сервис используется в корпоративном портале АО «Зарубежнефть» для отображения QR-кода в карточках сотрудников.

---

## Основное назначение

Микросервис принимает параметры сотрудника через HTTP GET-запрос  
и возвращает **PNG-изображение QR-кода**, внутри которого зашифрована визитка **vCard 3.0**.  
vCard поддерживается всеми современными устройствами (iOS / Android).

---

## Эндпоинты

| Метод | Путь | Назначение |
|:------|:------|:-----------|
| `GET` | `/vcard` | Генерация QR-кода с визиткой сотрудника |
| `GET` | `/healthz` | Проверка живости контейнера (Docker healthcheck) |

---

## Пример запроса

**GET-запрос:**

/vcard?fn=Петров+Иван+Иванович
&org=ЗН+Цифра
&title=Разработчик
&dept=Отдел+ИТ
&email=IPetrov@nestro.ru
&mobile=+79991234567
&work_short=002-8042
&filename=petrov_vcard


**Результат:**  
Возвращается PNG-файл `petrov_vcard.png` с QR-кодом, содержащим корректную структуру визитки vCard 3.0.  
Файл открывается прямо в браузере (`Content-Disposition: inline`).

---

## Конфигурация

Все параметры генерации управляются файлом `config/qr_config.json`.  
Он перечитывается при каждом запросе — изменение значений не требует пересборки Docker-образа.

### Пример `qr_config.json`

```json
{
  "QR_SIZE": 512,
  "QR_BORDER_PX": 6,
  "QR_FILL": "#009639",
  "QR_BG": "#FFFFFF",
  "QR_FINDER": "#EAAA00",
  "QR_LOGO": "assets/logo.png",
  "QR_LOGO_RATIO": 0.5,
  "QR_LOGO_PAD": 0.5,
  "QR_LOGO_PAD_RADIUS": 0,
  "QR_EC": "H",
  "VCARD_EXT_BASE": "+74957486424",
  "WORKERS": 2
}
## Пояснения параметров

| Параметр             | Описание                                                      |
| -------------------- | ------------------------------------------------------------- |
| `QR_SIZE`            | Размер итогового QR-кода в пикселях                           |
| `QR_BORDER_PX`       | Внешняя рамка (отступ) в пикселях                             |
| `QR_FILL`            | Цвет заливки модулей QR                                       |
| `QR_BG`              | Цвет фона QR                                                  |
| `QR_FINDER`          | Цвет угловых маркеров (finder-паттернов)                      |
| `QR_LOGO`            | Путь к логотипу компании                                      |
| `QR_LOGO_RATIO`      | Размер логотипа относительно QR (0–1)                         |
| `QR_LOGO_PAD`        | Масштаб подложки под логотип                                  |
| `QR_LOGO_PAD_RADIUS` | Радиус скругления подложки                                    |
| `QR_EC`              | Уровень коррекции ошибок (`H` или `Q`)                        |
| `VCARD_EXT_BASE`     | Основной рабочий номер (используется для формирования «доб.») |
| `WORKERS`            | Количество процессов uvicorn при запуске                      |

## Запуск через Docker

### Сборка образа
\```bash
docker build -t qr-vcard-service:latest .
\```

### Запуск контейнера
\```bash
docker-compose up --build
\```

После старта:  
- API доступно по адресу: **http://localhost:8000/vcard**  
- Проверка состояния контейнера: **http://localhost:8000/healthz**

---

## Запуск вручную (локально)

\```bash
pip install -r requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000
\```
